# 📄 Portfólio em HTML (sem CSS)

Este projeto é um **portfólio acadêmico** desenvolvido apenas com **HTML5**, sem uso de CSS ou frameworks.  
Foi criado como **atividade escolar**, com o objetivo de praticar a organização semântica do HTML e explorar recursos nativos como tabelas, listas, `<progress>`, `<details>`, `<blockquote>` e também o uso de **SVG** para criar cabeçalhos visuais.

---

## 🎯 Objetivos do projeto
- Exercitar a estruturação semântica em HTML5;  
- Montar um currículo online simples;  
- Estilizar sem CSS, utilizando apenas recursos do próprio HTML e SVG;  
- Experimentar elementos pouco usados como `<meter>`, `<progress>`, `<details>`.

---

## 📂 Estrutura do projeto
- **index.html** → Página principal com informações pessoais, contato, competências e formação.  
- **experiencia.html** → Página complementar detalhando experiências profissionais.  

---

## 📝 Observações
Este projeto foi desenvolvido apenas como atividade de estudo e prática.  
Não há intenção de uso profissional, mas serve como base para aprendizado e como exemplo de portfólio em HTML puro.
